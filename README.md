# 豆位 DouWei

Android 模拟定位与道路轨迹回放工具，支持百度地图、高德地图。当前版本 **2.5.18**。

**看不惯动不动就收费，所以把豆位免费开源。** 下载、使用本软件不收取费用，希望有需要的人可以自己配置地图 Key、自己编译和学习。

[下载安装包](https://github.com/laozhangaa/DouWei/releases/latest) · [地图 Key / AK 申请教程](docs/MAP_KEYS.md) · [本版说明](dist/豆位-2.5.18-说明.md)

## 功能

- **模拟定位**：地图选点、地点搜索、省市选择、经纬度输入、位置微调。
- **双地图**：默认百度，可在设置中切换高德；地图凭据由使用者自行填写。
- **道路规划**：驾车、骑行、步行、跑步，支持途经点和服务返回的多路线方案。跑步使用步行道路。
- **驾车偏好**：推荐路线、躲避拥堵、少收费、时间优先；不走高速、高速优先由高德提供。
- **行驶模式**：匀速，或带起步加速、制动及弯道降速的真实行驶模拟。速度可设置为 1～500 km/h，真实行驶以它作为速度上限。
- **路口停车**：显示官方路线接口返回的全程红绿灯数量，可开启模拟停车。停车点根据道路和路口信息估算，**不是实时灯位、灯色或倒计时**。
- **播放控制**：暂停、继续、停止、进度调整、回到起点。意外退出后可手动恢复未完成路线；重开软件不会自动启动模拟。
- **收藏备份**：位置和完整道路路线收藏、重命名、单条删除，JSON 导出与校验合并导入。备份不包含地图 Key / AK。
- **状态与诊断**：首页同步运行状态，显示定位写入、权限、省电及更新间隔；历史记录支持长按单条删除。
- **简洁界面**：直接进入主页，36dp 半透明悬浮地图；已移除在线更新和应用内下载推广入口。

## 安装与使用

1. 在 [Releases](https://github.com/laozhangaa/DouWei/releases/latest) 下载签名 APK；仓库的 [dist](dist/) 也包含同一安装包和 SHA-256 校验文件。
2. 按下方信息申请自己的 Android 地图凭据，在豆位右上角 **设置 → 地图服务** 选择地图并填写对应凭据。另一家暂不使用时可以留空。
3. 开启手机开发者选项，在“选择模拟位置信息应用”中选择“豆位”，按页面提示授予定位和悬浮窗权限。
4. 选择位置，或设置起终点并规划道路，再启动模拟。后台运行受限时，可在运行诊断中检查权限和省电设置。

本软件通过 Android 系统模拟定位 API 工作，未 Root 手机也可使用。第三方 App 是否采用模拟位置取决于其定位方式、缓存与检测策略，不能保证所有 App 兼容。

## 编译

环境：JDK 17、Android SDK（compileSdk 31）、Gradle 7.6.4（已配置 Wrapper）。

1. 将 `local.properties.example` 复制为 `local.properties`。
2. 设置本机 `sdk.dir` 和自己的 `SIGNING_STORE_FILE`、`SIGNING_KEY_ALIAS`、`SIGNING_STORE_PASSWORD`、`SIGNING_KEY_PASSWORD`。
3. 在 Windows PowerShell 执行：

```powershell
.\gradlew.bat :app:testReleaseUnitTest :app:assembleRelease :app:lintRelease
```

macOS / Linux 使用 `bash ./pack.sh`。输出为 `app/build/outputs/apk/release/app-release.apk`。

当前工程的 debug 和 release 都使用本地配置的签名，请先补全签名配置。签名文件、密码、`local.properties` 和构建缓存均不提交；地图凭据在手机应用内填写，无需写进源码。

## 路线与红绿灯说明

路线来自所选地图的官方 SDK。官方地图 App 的实时路况、路线偏好和候选方案可能与 SDK 默认结果不同，可选择相同的服务、具体起终点和偏好进行对照。收藏路线使用保存的道路轨迹。

内部道路坐标统一为 GCJ-02，写入系统定位时转换为 WGS-84。百度地图及百度定位也配置为 GCJ-02，不能额外套一层 BD-09 转换。

高德路线使用 `DrivePathV2.cost.trafficLights`，百度使用 `DrivingRouteLine.lightNum` 获取**全程灯数**。本版没有接入实时信号灯状态；模拟停车只用于轨迹回放，不能用于真实道路通行判断。
